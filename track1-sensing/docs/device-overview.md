# เครื่องวัดค่าความจุไฟฟ้าระดับ pF และความชื้นเมล็ดกาแฟ — ทีม TGR-20

TESA TOP GUN RALLY 2026 #20 · Track 1: Precision Sensing (ESP32 & Sensor)

## 1. อุปกรณ์นี้คืออะไร

เครื่องวัด**ค่าความจุไฟฟ้า (C) ระดับพิโคฟารัด** ที่ใช้ ESP32-S3 เป็นตัวประมวลผล ใช้ได้สองงาน
บนฮาร์ดแวร์ชุดเดียวกัน:

| งาน | ต่ออะไรที่ตำแหน่ง Cx | ผลที่ส่งออก |
|---|---|---|
| วันที่ 18 พ.ย. วัดตัวเก็บประจุ | ตัวเก็บประจุเซรามิกที่ไม่ทราบค่า | `Capacitance = xx.xx pF` |
| วันที่ 20 พ.ย. วัดความชื้นกาแฟ | กล่องเซ็นเซอร์ PCB สองแผ่นบรรจุเมล็ดกาแฟ | `Moisture Level = xx.xx %` |

กดปุ่มหนึ่งครั้ง เครื่องวัดหนึ่งครั้ง แล้วส่งผลทาง Serial Port ที่ 9600 baud

## 2. หลักการทำงาน

### 2.1 ความชื้นทำให้ค่าความจุเปลี่ยน

ตัวเก็บประจุแบบแผ่นขนานมีค่า

```
C = ε₀ · εr · A / d
```

เซ็นเซอร์คือแผ่น PCB ขนาด 5 × 10 cm สองแผ่น วางห่างกัน 1 cm ในกล่องพลาสติก เมล็ดกาแฟที่เทลงไป
เป็น**ไดอิเล็กทริก**ระหว่างแผ่น น้ำมีค่าคงที่ไดอิเล็กทริก εr ≈ 80 ส่วนเนื้อเมล็ดแห้งมีราว 2–4
เมล็ดยิ่งชื้น εr รวมยิ่งสูง ค่า C ยิ่งสูง

```
ความชื้น ↑  →  εr ↑  →  C ↑
```

### 2.2 วัด C ด้วยการจับเวลาชาร์จ RC

ชาร์จตัวเก็บประจุผ่านตัวต้านทาน R = 1 MΩ แรงดันขึ้นตาม

```
Vc(t) = Vcc · (1 − e^(−t/RC))
```

เครื่องจับเวลาตั้งแต่เริ่มชาร์จจน Vc แตะแรงดันอ้างอิง Vref

```
t = R · C · ln( Vcc / (Vcc − Vref) )
```

ตั้ง Vref ≈ 0.632 × Vcc (2.088 V จาก 3.3 V) ทำให้ ln(...) ≈ 1 จึงได้ **t ≈ R·C** และเพราะ R = 1 MΩ
**1 µs ≈ 1 pF** ค่า Vref นี้เป็นจุดที่ความคลาดเคลื่อนจาก noise ต่อเวลาที่วัดได้น้อยที่สุดตามทฤษฎีด้วย

ตัวที่บอกว่า "แตะ Vref แล้ว" คือ comparator **LM393** ซึ่งเปลี่ยนสถานะเอาต์พุตทันทีที่ Vc แซง Vref
(วิธีที่ 1 ในสไลด์ แบบ inverting)

## 3. ฮาร์ดแวร์

### 3.1 อุปกรณ์ที่ใช้ (ทั้งหมดจากคิตที่ฝ่ายจัดแจก ยกเว้นบอร์ด ESP32)

| อุปกรณ์ | หน้าที่ |
|---|---|
| ESP32-S3 N16R8 (บอร์ดตระกูล YD-ESP32-S3) | ประมวลผล จับเวลา ส่งผล |
| R 1 MΩ | ตัวต้านทานชาร์จ |
| LM393 | เปรียบเทียบ Vc กับ Vref |
| Trimpot 10 kΩ | สร้าง Vref ≈ 2.088 V |
| R 10 kΩ | pull-up ขาเอาต์พุต LM393 (open-collector) |
| สวิตช์กดติดปล่อยดับ | ปุ่มเริ่มวัด |
| ตัวเก็บประจุ 5 / 10 / 15 / 20 pF | ตัวอ้างอิงสำหรับสอบเทียบ |
| แผ่น PCB 2 แผ่น + กล่องพลาสติก | เซ็นเซอร์ความชื้น |

### 3.2 วงจร

```
GPIO5 (ชาร์จ) ── R 1MΩ ──┬── LM393 ขา 2 (IN1−)
                         └── Cx (ตัวเก็บประจุ หรือ เซ็นเซอร์) ── GND

3.3V ── trimpot 10k ── GND,   ขากลาง (Vref ≈ 2.088 V) ── LM393 ขา 3 (IN1+)

LM393 ขา 1 (OUT1) ── R 10k ── 3.3V
                  └── GPIO6 (อ่านผล)

LM393 ขา 8 ── 5V,   ขา 4 ── GND,   ขา 5 ── GND,   ขา 6 ── ขา 3   (ล็อกคอมพาเรเตอร์ตัวที่ 2)

GPIO4 ── สวิตช์ ── GND          (debounce ด้วยซอฟต์แวร์)
GPIO48 = RGB LED บนบอร์ด
```

| ขา | หน้าที่ |
|---|---|
| GPIO4 | ปุ่มกด |
| GPIO5 | สั่งชาร์จ / คายประจุ |
| GPIO6 | รับสัญญาณจาก LM393 |
| GPIO48 | LED บนบอร์ด |
| GPIO43/44 | Serial (ผ่านชิป CH343 บนบอร์ด) |

### 3.3 จุดออกแบบที่สำคัญ

- **LM393 เลี้ยงด้วย 5 V** — ที่ไฟ 3.3 V LM393 รับอินพุตได้แค่ถึง 1.8 V (Vcc − 1.5 V)
  ต่ำกว่า Vref ที่ 2.088 V ที่ 5 V รับได้ถึง 3.5 V
- **pull-up ต่อ 3.3 V ไม่ใช่ 5 V** — เอาต์พุต LM393 เป็น open-collector จึงดึงขึ้นที่แรงดันไหนก็ได้
  ขา GPIO ของ ESP32 จึงไม่โดนไฟ 5 V
- **Vref และไฟชาร์จใช้ 3.3 V เส้นเดียวกัน** — ไฟขยับแล้วทั้งสองฝั่งขยับพร้อมกันในสัดส่วนเดียวกัน
  เวลาที่วัดได้ไม่เปลี่ยน (ratiometric)
- **เซ็นเซอร์หันด้านทองแดงออก** — แผ่นใยแก้วของ PCB เป็นฉนวนกั้นระหว่างทองแดงกับเมล็ด
  ไม่มีกระแสรั่วผ่านเมล็ดชื้น แผ่นที่ต่อ GND หันเข้าหาผู้ใช้เพื่อบังสนามไฟฟ้าจากมือ

### 3.4 สิ่งที่ต้องแก้บนบอร์ด

บอร์ดตระกูลนี้มีจุดบัดกรีสองจุดที่เปิดวงจรไว้ตั้งแต่โรงงาน ต้องเชื่อมก่อนใช้งาน

| จุด | อาการถ้าไม่เชื่อม |
|---|---|
| `IN-OUT` | ขา 5V จ่ายไฟออกได้แค่ ~1.8 V LM393 ไม่ทำงาน |
| `RGB` | LED บน GPIO48 ไม่ติด |

## 4. ซอฟต์แวร์

### 4.1 ลำดับการทำงานเมื่อกดปุ่ม

```
กดปุ่ม ─► LED บนบอร์ดติด 200 ms ทันที                       (กติกาข้อ 3.4)
ปล่อยปุ่ม ─► debounce 30 ms ─► รอ 200 ms ให้มือถอยห่าง
         ─► ชาร์จ-จับเวลา 510 รอบ (~0.51 s)
         ─► คำนวณ ─► ส่งผล                               ≈ 0.75 s หลังปล่อยปุ่ม
```

กดหนึ่งครั้งได้ผลหนึ่งครั้งเสมอ การกดระหว่างที่เครื่องกำลังวัดจะถูกทิ้ง (กติกาข้อ 3.3)

### 4.2 การจับเวลา

- นับด้วย **ตัวนับรอบนาฬิกาของ CPU** ที่ 240 MHz ละเอียด 4.17 ns
  (ละเอียดกว่า `micros()` 240 เท่า)
- **ปิด interrupt** ระหว่างจับเวลาแต่ละรอบ กัน FreeRTOS / USB มาขัดจังหวะ
- อ่าน/เขียนรีจิสเตอร์ GPIO ตรง แทน `digitalRead()` / `digitalWrite()`
- **Dithering** — การอ่านขา GPIO หนึ่งครั้งใช้ราว 30 รอบนาฬิกา ขอบสัญญาณจึงถูกเห็นเป็นขั้นๆ ละ 0.125 µs
  เครื่องเลื่อนจังหวะเริ่มอ่านไปทีละนิด (0–239 รอบนาฬิกา) ในแต่ละรอบ การเฉลี่ยจึงละเอียดกว่าขั้นนั้น

### 4.3 การลดสัญญาณรบกวน

- **วัด 500 รอบแล้วเฉลี่ย** ตัดค่าสูงสุดและต่ำสุดทิ้งฝั่งละ 10% (trimmed mean)
- **ล็อกจังหวะกับไฟบ้าน 50 Hz** — แผ่นเซ็นเซอร์ขนาดใหญ่รับสัญญาณรบกวนจากไฟบ้านได้
  เครื่องเริ่มชาร์จแต่ละรอบห่างกันพอดี 1.000 ms รวม 500 ms = 25 คาบเต็มของ 50 Hz
  สัญญาณรบกวนส่วนบวกกับส่วนลบจึงหักล้างกันในค่าเฉลี่ย

### 4.4 การแปลงผล

**เวลา → pF** (สอบเทียบด้วยตัวเก็บประจุ 20 pF, ความชันตามทฤษฎี)

```
C [pF] = 0.99835 × t [µs] − 13.314
```

ค่า −13.314 pF คือ **C แฝง** ของวงจร (สาย เบรดบอร์ด ขา LM393 และความหน่วงของ comparator)

**pF → ความชื้น** (linear regression จากเมล็ดอ้างอิง 3 ระดับ ที่ 35 g)

```
M [%] = 0.48468 × C [pF] − 0.8334          R² = 0.99997
```

| ความชื้นอ้างอิง | C ที่วัดได้ | ความชื้นที่ทำนาย |
|---|---|---|
| 7.7% | 17.63 pF | 7.71% |
| 11.3% | 24.99 pF | 11.28% |
| 14.5% | 31.66 pF | 14.51% |

### 4.5 รูปแบบข้อมูลที่ส่ง (กติกาข้อ 3.2, 3.5)

Serial 9600 baud:

```
"TGR-20"
Moisture Level = 11.28 %

```

(รอบวัดตัวเก็บประจุ: `Capacitance = xx.xx pF`) ถ้าวงจรไม่ตอบสนอง เครื่องจะไม่ส่งค่าใดๆ
แทนที่จะส่งตัวเลขที่ไม่ได้มาจากการวัด

## 5. ประสิทธิภาพ

| รายการ | ผล |
|---|---|
| ความนิ่ง (กดซ้ำ ตัวอย่างเดิม) | ห่างกันราว 0.01–0.05 pF ≈ 0.005–0.02% ความชื้น |
| ความไวของเซ็นเซอร์ | ~2.06 pF ต่อความชื้น 1% |
| เวลาตอบสนอง | ~0.75 วินาทีหลังปล่อยปุ่ม (เกณฑ์คะแนนเต็ม ≤ 3 วินาที) |
| ตัวเก็บประจุอ้างอิง 20 pF | อ่านได้ 19.97 pF |

## 6. วิธีใช้งาน (รอบความชื้น)

1. **กล่องเซ็นเซอร์ต้องว่าง** แล้วเสียบสาย USB ช่อง UART (CH343) มือออกห่างกล่อง
   รอ 3 วินาที เครื่องจะวัดกล่องเปล่าเองแล้วชดเชย C แฝงที่เปลี่ยนไปจากตอนสอบเทียบ
   (ถ้าเปิดเครื่องตอนมีเมล็ดอยู่ เครื่องจะข้ามการชดเชยและใช้ค่าเดิม)
2. เปิด Serial Monitor ที่ 9600 แล้วเทเมล็ดกาแฟ **35 g** ลงช่องกลางของกล่องเซ็นเซอร์ ช่องนอกปล่อยว่าง ปาดหน้าให้เรียบ
3. รอราว 5 วินาที มือออกห่างกล่อง
4. กดปุ่มแล้วปล่อย ไฟ LED ติด ค่าความชื้นขึ้นบนจอภายในราว 1 วินาที

## 7. ข้อจำกัด

- ปริมาณเมล็ดต้องเท่ากับตอนสอบเทียบ (35 g) ปริมาณต่างทำให้ C ต่างโดยไม่เกี่ยวกับความชื้น
- วิธีเทเมล็ดมีผลต่อความแน่นของเมล็ดในกล่อง ซึ่งเป็นแหล่งความคลาดเคลื่อนหลักที่เหลืออยู่
- C แฝงขึ้นกับการวางสายและสิ่งรอบข้าง (เห็นแกว่ง 10.8–12.3 pF) เครื่องชดเชยให้ด้วยการวัดกล่องเปล่า
  ตอนเปิดเครื่อง ซึ่งต้องเปิดตอนกล่องว่างเท่านั้น
- สมการความชื้นสอบเทียบในช่วง 7.7–14.5% นอกช่วงนี้เป็นการต่อเส้นออกไป
- เมล็ดกาแฟดูดและคายความชื้นตามอากาศ ค่าอ้างอิงที่ใช้สอบเทียบต้องตรงกับสภาพเมล็ดตอนวัด
