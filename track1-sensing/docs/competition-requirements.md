## 2. น้ำหนักคะแนน

- วัดตัวเก็บประจุ = **40%**
- วัดความชื้นเมล็ดกาแฟ = **55%**
- รวม 95% — เอกสารไม่ระบุว่าอีก 5% มาจากไหน (ข้อ 1.7) → **ต้องถามกรรมการ**

## 3. ข้อบังคับฮาร์ดแวร์

- เซ็นเซอร์: **ต้องใช้ของที่ฝ่ายจัดเตรียมให้เท่านั้น** — กล่องพลาสติก 3 ช่อง + แผ่นปริ้นท์ (PCB) 5.00 × 10.00 cm จำนวน 2 แผ่น
  - ระยะช่องก่อนใส่แผ่น 1.25 cm, **หลังใส่แผ่นแล้วเหลือ 1.00 cm** ← นี่คือ `d`
- ไมโครคอนโทรลเลอร์: **ESP32 ไม่จำกัดเวอร์ชัน** (ESP32-S3 N16R8 ของเราใช้ได้)
- ห้ามใช้อุปกรณ์อื่นนอกเหนือจากที่แจก

อุปกรณ์ที่แจก (ข้อ 2.3):

| รายการ | จำนวน | ใช้ทำอะไร (ตามสไลด์) |
|---|---|---|
| LM393 (dual comparator) | 1 | เปรียบเทียบ Vc กับ Vref / สร้างออสซิลเลเตอร์ |
| Trimpot 10 kΩ (25 รอบ) | 1 | ปรับ Vref ละเอียด (0–3.3 V) |
| R 1 MΩ | 1 | ตัวต้านทานชาร์จ RC |

| R 2 kΩ | 1 | — |
| C เซรามิก 5, 10, 15, 20 pF | อย่างละ 1 | **ตัวอ้างอิงสำหรับสอบเทียบ** |
| C 0.1 µF | 1 | debounce สวิตช์ (τ = 10k × 0.1µ ≈ 1 ms) |
| สวิตช์กดติดปล่อยดับ | 1 | ปุ่มเริ่มวัด |
| สติกเกอร์ | 2 | เขียนรหัส/ชื่อทีมติดเครื่อง |

## 4. โปรโตคอลที่พลาดไม่ได้ (ข้อ 3)

- **Serial baud rate = 9600** (ไม่ใช่ 115200)
- **สวิตช์: กด 1 ครั้งแล้วปล่อยมือ = วัด 1 ครั้ง** — กดพลาด เครื่องไม่ทำงาน หรือกดซ้ำ → ครั้งนั้น **ได้ 0**
- **ทุกครั้งที่ส่งค่า LED บนบอร์ด ESP32 ต้องสว่าง 200 ms**
- ต้องแสดงรหัสทีมของตนเองทุกครั้ง

รูปแบบข้อความ (ต้องตรงเป๊ะ รวมเครื่องหมายคำพูด ทศนิยม 2 ตำแหน่ง และบรรทัดว่างคั่น):

```
"TGR-01"
Capacitance = 10.00 pF

"TGR-01"
Capacitance = 11.55 pF
```

```

Moisture Level = 10.00 %
```

## 5. ขั้นตอนการส่งงานและตรวจ (ข้อ 4)

- ส่งเฉพาะ **เครื่องวัด** ที่โต๊ะส่งงาน ลานหน้าโรงอาหาร; เขียนรหัส + ชื่อทีมให้ชัดเจน
- **หลังส่งงานห้ามแก้ไขฮาร์ดแวร์และโค้ดอีกทุกกรณี — ฝ่าฝืน = 0 คะแนน**
- อุบัติเหตุ (สายหลุด ฯลฯ) ผู้เข้าแข่งขันรับผิดชอบเอง; อุบัติเหตุที่เกิดจากฝ่ายจัด กรรมการพิจารณาเป็นกรณีไป
- แบ่ง 4 กลุ่มย่อย กลุ่มละ 14 ทีม; 1 คน/ทีม เข้าไลน์กลุ่มย่อยผ่าน QR code ที่โต๊ะ
- ตอนวัด ส่งตัวแทน **2 คน**: คนที่ 1 กดสวิตช์, คนที่ 2 **ถ่ายคลิปวิดีโอ**; กรรมการให้สัญญาณเริ่ม
- คลิปต้องเห็น **จังหวะกดสวิตช์** และ **ค่าที่หน้าจอทุกครั้ง** — ไม่เห็น = ครั้งนั้นได้ 0
- ส่งคลิปเข้าไลน์กลุ่มย่อย โดยพิมพ์รหัสทีมตามด้วยคลิป

## 6. การวัดและการให้คะแนน (ข้อ 5)

- 2 ตัวอย่าง × **5 ครั้ง** ต่อตัวอย่าง
- pF: กรรมการแจ้งค่าจริงหลังแข่งเสร็จ
- ความชื้น: ค่ามาตรฐานมาจากเครื่องวัดมาตรฐาน วัด 5 ครั้งแล้วเฉลี่ย (ตัวแทนกลุ่มร่วมยืนยัน)

สูตรตามเอกสาร (เขียนไว้แบบนี้จริง — ดูหมายเหตุ):

```
%Error = | (x1+x2+x3+x4+x5)/N − ค่ามาตรฐาน | · 100
%RMSE  = sqrt( (e1²+e2²+e3²+e4²+e5²)/N ) · 100     โดย e = ค่าที่วัดได้ − ค่ามาตรฐาน
```

| %Error | คะแนน | | %RMSE | คะแนน |
|---|---|---|---|---|
| 0–10 | 10 | | ≤ 2 | 10 |
| >10–15 | 9 | | >2–5 | 9 |
| >15–20 | 8 | | >5–10 | 8 |
| >20–25 | 7 | | >10–15 | 7 |
| >25–30 | 6 | | >15–20 | 6 |
| >30–35 | 5 | | >20–25 | 5 |
| >35–40 | 4 | | >25–30 | 4 |
| >40–45 | 3 | | >30–35 | 3 |
| >45–50 | 2 | | >35–40 | 2 |
| >50–55 | 1 | | >40–45 | 1 |
| >55 | 0 | | >45 | 0 |
| เครื่องไม่ทำงาน/วัดไม่ได้ | 0 | | วัดไม่ได้ | 0 |

Response time (กดสวิตช์ → ค่าขึ้นหน้าจอ): 0–3 s = 5, >3–6 = 4, >6–9 = 3, >9–12 = 2, >12–15 = 1, **"เกิน 13 วินาที = 0"** (ขัดแย้งกันเอง — ตั้งเป้า < 3 s ไปเลย)

เกณฑ์ตัดสินเสมอ: %Error → %RMSE → Response time
รางวัล: **Top Score on Precision Sensing**

## 7. หลักการทางฟิสิกส์ (จากสไลด์)

```
ความชื้นในเมล็ด ↑  →  εr รวม ↑  →  C ↑
```

- น้ำ εr ≈ 80, เมล็ดแห้ง/เซรามิกอินทรีย์ εr ≈ 2–4
- `C = ε0 · εr · A / d` โดย ε0 = 8.854e-12 F/m
- ช่วงความชื้นที่ดีของกาแฟสาร = **10–12%** (>12% ขึ้นรา, <10% เมล็ดเปราะ)

**ค่าที่คำนวณได้จากขนาดเซ็นเซอร์จริง** (A = 0.05 × 0.10 = 5e-3 m², d = 0.01 m):

```
C_อากาศ (กล่องว่าง) = 8.854e-12 × 5e-3 / 0.01 ≈ 4.43 pF
C_มีเมล็ดกาแฟ (εr ≈ 2–3) ≈ 9–13 pF
```

## 8. เทคนิคการวัดที่สไลด์เสนอ

| วิธี | วงจร | หลักการ |
|---|---|---|
| 1 | RC + LM393 | ชาร์จผ่าน R1=1M, จับเวลาจน Vc ถึง Vref = 0.632·Vcc = **2.086 V** → τ = RC → `C = t/R` ใช้ external interrupt |
| 2 | RC + ADC | อ่าน ADC ต่อเนื่องจน Vc ≥ 2.086 V แล้วจับเวลา → `C = t/R` |
| 3 | Fixed time + ADC | ชาร์จเวลาคงที่ t_ch แล้วอ่าน Vc → `Cx = −t_ch / (R1 · ln(1 − Vc/Vcc))` |
| 4 | อื่น ๆ | ออสซิลเลเตอร์วัดความถี่ หรือวิธีที่คิดเองได้ |

Vref = 2.086 V ทำได้ 2 แบบ: ตัวแบ่งแรงดัน R2=10k/R3=17.2k หรือ **trimpot 25 รอบ** (ปรับละเอียดกว่า)
Debounce สวิตช์: R 10k + C 0.1 µF คร่อมสวิตช์ → τ ≈ 1 ms

## 9. ประเด็นที่ต้องถามกรรมการ

1. คะแนน 40% + 55% = 95% — อีก 5% คืออะไร
2. สูตร %Error/%RMSE **ไม่ได้หารด้วยค่ามาตรฐาน** — คูณ 100 เฉย ๆ ถ้าตีความตามตัวอักษร ผิด 0.1 pF จะกลายเป็น "10%" ทันที ใช้สูตรไหนกันแน่
3. Response time: ">12 น้อยกว่า 15 วินาที ได้ 1" แต่ "เกิน 13 วินาที ได้ 0" — ขัดกัน
4. ใช้เบรดบอร์ด/สายของตัวเองได้ไหม (เอกสารแจกแค่ "สายเชื่อมต่อวงจร 1 ชุด")
5. "หน้าจอ" ในคลิปวิดีโอ = จอโน้ตบุ๊กที่เปิด Serial Monitor ใช่หรือไม่
6. วัด 5 ครั้งติดกันโดยไม่แตะเมล็ด หรือต้องเทเมล็ดใหม่ทุกครั้ง (กระทบ %RMSE มาก)
