# คู่มือระหว่างแข่ง ด่าน 3 (20 พ.ย.)

## กติกาที่ใช้ (ผู้จัดยืนยัน)
- ระหว่างที่ agent รัน **แก้โค้ดได้ ทั้งแก้เองหรือให้ AI ภายนอกช่วยแก้ (เช่น Claude Code)** ไม่นับว่าใช้ LLM ภายนอก เพราะเป็นการซ่อมหรือพัฒนา agent
- แก้ได้**เฉพาะ Code, Algorithm และ Logic เท่านั้น**
- ตัว agent ตอนรันใช้ LLM ได้แค่ gateway ของงาน (เราตั้ง `USE_LLM=0` ใช้กฎล้วน)
- **ห้ามส่ง แก้ หรือยกเลิกข้อเสนอด้วยมือ** (เว็บ, curl, Postman, สคริปต์สั่งทีละคำสั่ง) ผิดข้อนี้ = ตัดสิทธิ์ทั้งการแข่ง
- ห้ามกดข้าม รีเซ็ต หรือ autoplay

### เราจึงยึด
| ✅ ทำได้ | ❌ ไม่ทำ |
|---|---|
| แก้กฎทั่วไปใน `strategy.py` เช่น "แพ้ 2 รอบติด ลดเพดาน 0.03" | ฝังข้อเสนอเจาะจงในโค้ด เช่น "LOT-2 ให้ R7-03 ราคา 118" (= ส่งด้วยมือแบบอ้อม) |
| แก้ค่าคงที่ใน `strategy.py` (เพดานตัวคูณ, ก้าวขึ้นราคา, การเก็บของรอเทศกาล) | แก้หรือลบ `logs/decisions.jsonl`, `logs/memory-*.json` (กรรมการใช้เทียบกับตลาด) |
